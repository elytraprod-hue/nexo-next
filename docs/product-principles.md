# Principios de produto

O NEXO Central nao deve reproduzir sistemas antigos de CRM, planilha ou gestao generica.

O produto existe para ajudar filmmakers, videomakers, freelancers, produtoras pequenas e agencias com operacao audiovisual a trabalharem com mais organizacao, velocidade e lucro.

## Regra de decisao

Quando existir mais de uma forma de implementar uma funcionalidade, escolher a que:

- exige menos cliques;
- exige menos digitacao;
- exige menos treinamento;
- escala melhor para milhares de usuarios;
- gera mais valor para profissionais e empresas do audiovisual.

## Implicacoes praticas

- Formularios longos sao excecao, nao padrao.
- Presets, playbooks, templates e automacoes devem ser priorizados.
- O usuario deve conseguir criar cliente, projeto, documento ou review em poucos segundos.
- O sistema deve sugerir a proxima melhor acao.
- Dados financeiros precisam caber em leitura rapida, com privacidade de valores.
- Review/aprovacao de video e o diferencial competitivo principal.

## Decisao desta etapa

A proxima camada apos migrar as telas principais foi a Command Palette/Quick Create.

Motivo:

- reduz cliques;
- reduz treinamento;
- permite criar registros sem navegar por menus;
- prepara a plataforma para automacoes futuras;
- combina com o uso diario de filmmakers que precisam resolver operacao rapido.

Tambem foram adicionados timeline operacional e alertas simples para que o sistema aponte o que importa antes do usuario precisar procurar.
